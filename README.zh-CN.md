## 项目特点

- **静态网站架构**：无需专用应用服务器或数据库即可运行基本网站。
- **许可证阅读页**：以纯文本展示原始许可证及授权范围文件，并提供原始文件下载入口。
- **学术风格设计**：采用简洁、克制的视觉风格，适合展示研究资料与文字内容。
- **响应式布局**：针对桌面设备和移动设备进行适配。
- **论文与成果展示**：提供用于发布文章、研究报告及其他成果的页面。
- **可复用的页面模板**：便于创建和扩展其他学术展示页面。
- **首次访问免责声明入口**：首页和文章页面要求访客阅读并确认免责声明；许可证阅读页有意跳过这一入口，以便许可证及授权范围信息始终可以直接访问。

## 本地运行

### 本地预览（推荐）

首页、文章页面和许可证阅读页会通过浏览器 `fetch()` 加载独立的界面文案、免责声明及原始许可文件。要完整预览网站，请通过 HTTP 静态服务器运行：

1. 克隆或下载本仓库，并进入项目目录。
2. 在仓库根目录执行：

   ```bash
   python -m http.server 8000
   ```

3. 在现代浏览器中打开 `http://localhost:8000/`。

不要通过 `file://` 直接打开网站的任何页面。首页、文章页面和许可证阅读页都依赖运行时内容请求，必须通过 HTTP 静态服务器访问。

### 使用 Git 克隆

```bash
git clone https://github.com/Aaibili/Able-Tach-Website.git
cd Able-Tach-Website
```

完成后，根据项目实际结构打开入口页面或启动本地静态服务器。

## 内容性质标签

文章页面通过 HTML `<head>` 中的 `content-nature` 元数据标明内容性质，支持以下取值：

- `fictional`：虚构创作。未设置标签或标签值无效时，默认按此类型处理。
- `hypothetical`：假设性研究、推演或模型，不代表真实实验或实际研究结果。
- `reference`：真实资料或有来源依据的现实信息整理。
- `research`：页面声明为现实研究成果；该标签只是页面的内容性质说明，不代表本站或任何机构已独立核验或认证。

`generate_article_pages.py` 会从 `Papers and Achievements/articles.json` 写入 `content-nature` 元数据。修改文章性质时，应保持该文件中的 `contentNature` 值与对应文章内容片段中的可见标签一致。随后，`generate_papers_manifest.py` 会生成 `papers.json` 清单；共享页面脚本会在运行时读取该清单并构建首页成果列表。真实资料或真实研究还应在适当情况下列出来源、作者、方法、数据及日期，供读者核查。

## 文章内容与网页程序代码分离

文章页面由独立的内容文件和网页程序代码生成：

- **文章正文与标记：** `Papers and Achievements/article-content/*.html`。这些文件是文章内容片段，不是完整的独立网页。
- **文章元数据：** `Papers and Achievements/articles.json`。用于关联文章 ID、生成后的 HTML 文件名、标题、简介、内容性质、正文片段和样式表。
- **共享界面文案：** `site-content/site-copy.json` 保存界面文字，`site-content/disclaimer.html` 保存免责声明正文。它们属于独立内容文件，不是可复用页面程序代码，也不纳入 GPL-3.0-only 授权范围。
- **可复用页面外壳：** `page-layouts/article-page.html`。
- **共享页面脚本：** `assets/js/article-page.js` 负责加载界面文案和文章内容、校验内容片段、管理免责声明入口、初始化首页成果列表，并为许可证阅读页读取原始许可文件。
- **文章样式表：** `assets/css/article-pages/`。
- **发布用文章页面：** `Papers and Achievements/` 下的 `.html` 文件属于生成结果。修改文章时，应编辑正文片段、元数据、模板或样式表，不要直接修改生成结果。

文章内容片段既包含正文，也包含用于组织文章的 HTML 结构（例如标题、章节、段落、表格、插图、图片说明及片段级属性）。按照本项目的授权安排，这些文章专属标记属于文章内容的一部分，不是可复用的页面框架。共享页面模板、通用 JavaScript 加载器、Python 生成脚本和列明的 CSS 样式表，分别承担可复用的布局、加载、校验、生成和呈现功能；它们仅在 `LICENSE-SCOPE.md` 明确规定的范围内适用 GPL-3.0-only。文章片段中的类名和数据属性可能与共享样式或加载器发生技术关联，但这种关联本身不改变项目声明的内容与程序代码边界。本说明表达的是项目的授权意图，并不对所有 HTML/CSS 组合的法律性质作出最终判断。

在仓库根目录依次执行以下命令，重新生成文章页面和首页成果清单：

```bash
python generate_article_pages.py
python generate_papers_manifest.py
```

`Papers and Achievements/` 中与文章同名的 `.txt` 文件仍用于首页列表中的简短简介。请保持文章内容片段中的可见内容性质标签与 `articles.json` 中的 `contentNature` 值一致。

网站会在运行时读取独立的界面文案、免责声明、文章元数据和文章正文。由于浏览器的 `fetch()` 不能直接读取 `file://` 下的本地文件，预览时请从仓库根目录启动 HTTP 静态服务器，例如：

```bash
python -m http.server 8000
```

然后在浏览器中打开 `http://localhost:8000/`。
