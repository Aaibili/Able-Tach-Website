Able-Tach-Website 是「田园研究所」的官方网站源代码仓库。这是一个以学术研究为主题的静态网站，主要围绕天文学、生物学及相关知识领域展开。

## 内容性质标签

文章页面通过 HTML `<head>` 中的 `content-nature` 元数据标明内容性质，支持以下取值：

- `fictional`：虚构创作。未设置标签或标签值无效时，默认按此类型处理。
- `hypothetical`：假设性研究、推演或模型，不代表真实实验或实际研究结果。
- `reference`：真实资料或有来源依据的现实信息整理。
- `research`：页面声明为现实研究成果；该标签只是页面的内容性质说明，不代表本站或任何机构已独立核验或认证。

`generate_papers_manifest.py` 会读取该元数据，并将标签写入 `papers.json` 与首页成果列表。修改页面性质时，应同时更新 HTML 元数据和文章标题区域的可见标签。真实资料或真实研究还应在适当情况下列出来源、作者、方法、数据及日期，供读者核查。
